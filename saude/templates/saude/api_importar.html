📌 Exemplos de resposta da API (formato JSON)

O sistema suporta dois formatos de dados para casos de doenças.

1. Formato tradicional (qualquer doença)

Campos obrigatórios:

  • provincia (string) – nome da província (ex: "Maputo")
  • doenca (string) – nome da doença (ex: "Malária")
  • data (string) – data no formato YYYY-MM-DD
  • quantidade (número) – total de casos
  • confirmados (número) – casos confirmados

Campos opcionais:

  • curados (número) – padrão 0
  • obitos (número) – padrão 0

Novos campos (opcionais, mas recomendados):

  • novos_casos (número) – novos casos no período
  • casos_acumulados (número) – total acumulado desde o início
  • novos_obitos (número) – novos óbitos no período
  • obitos_acumulados (número) – total de óbitos acumulados

Se estes novos campos forem fornecidos, serão armazenados nos respectivos campos do modelo.

[
  {"provincia": "Maputo", "doenca": "Malária", "data": "2026-07-01", "quantidade": 150, "confirmados": 120, "curados": 100, "obitos": 5, "novos_casos": 10, "casos_acumulados": 1200},
  {"provincia": "Gaza", "doenca": "Cólera", "data": "2026-06-30", "quantidade": 45, "confirmados": 40, "curados": 35, "obitos": 2, "novos_casos": 5, "casos_acumulados": 300}
]
2. Formato OMS (especialmente para COVID-19)

Se a API retornar dados no padrão da OMS, o sistema detecta automaticamente e cria os registos sem necessidade de mapeamento manual.

Campos esperados (os nomes são case‑insensitive):

  • Date_reported (string) – data
  • Country_code (string) – código do país (ex: "MZ") – o sistema filtra apenas Moçambique
  • Country (string) – nome do país
  • WHO_region (string) – região OMS (opcional)
  • New_cases (número) – novos casos
  • Cumulative_cases (número) – casos acumulados
  • New_deaths (número) – novos óbitos
  • Cumulative_deaths (número) – óbitos acumulados

Neste formato, a doença COVID-19 é criada automaticamente se não existir, e os dados são atribuídos à província "Moçambique".

[
  {"Date_reported": "2026-07-01", "Country_code": "MZ", "Country": "Mozambique", "WHO_region": "AFRO", "New_cases": 50, "Cumulative_cases": 1500, "New_deaths": 2, "Cumulative_deaths": 45},
  {"Date_reported": "2026-07-02", "Country_code": "MZ", "Country": "Mozambique", "WHO_region": "AFRO", "New_cases": 70, "Cumulative_cases": 1570, "New_deaths": 3, "Cumulative_deaths": 48}
]

📌 Notas importantes:

  • O sistema identifica o formato automaticamente – não precisa de escolher.
  • Para dados tradicionais, a doença deve existir previamente ou ser fornecida no campo doenca.
  • Para dados OMS, a doença COVID-19 será criada se não existir.
  • Os campos antigos (quantidade, confirmados, etc.) são mantidos para compatibilidade com dashboards existentes.
