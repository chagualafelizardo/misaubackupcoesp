📌 Exemplo de resposta da API (formato JSON)

A API deve retornar uma lista de objetos com os seguintes campos (obrigatórios para casos):

  • provincia (string) – nome da província (ex: "Maputo")
  • doenca (string) – nome da doença (ex: "Malária")
  • data (string) – data no formato YYYY-MM-DD
  • quantidade (número) – total de casos
  • confirmados (número) – casos confirmados
  • curados (número, opcional) – casos curados (padrão 0)
  • obitos (número, opcional) – óbitos (padrão 0)
[
  {"provincia": "Maputo", "doenca": "Malária", "data": "2026-07-01", "quantidade": 150, "confirmados": 120, "curados": 100, "obitos": 5},
  {"provincia": "Gaza", "doenca": "Cólera", "data": "2026-06-30", "quantidade": 45, "confirmados": 40, "curados": 35, "obitos": 2}
]

📌 Nota: Se os campos curados e obitos não forem enviados, o sistema assume 0.
